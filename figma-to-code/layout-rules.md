# figma-to-code レイアウト変換の規律（座標転記の禁止）（正本）

SKILL.md の Step 3（実装）と Step 5（統合検証）が参照する正本。**実装を別の主体（サブエージェント等）へ委譲するときは、本ファイルを要約せず全文を委譲プロンプトへ転記する**（本ファイルを渡さずに「デザインと一致させよ」とだけ指示すると、実装側は座標転記で一致を達成し、後述の破綻を実装時点では検出できない）。

**なぜ必要か**: design context / metadata が返す各ノードの `x, y, width, height` をそのまま `position: absolute; left; top` に書き写すと、デザイン幅・デザインの文言・デザインのフォントが揃った一点でだけ数値照合が満点になる。しかし親の高さが子から決まらない構造になるため、文言の長さ・要素数・フォント読込・ビューポート幅のいずれかが変わった瞬間に重なりや溢れが起きる。その破綻を `white-space: nowrap` や親の固定高で隠すと局所修正が連鎖し、後から全体をフローへ組み直す工数が実装工数を上回る。座標転記は「最短で数値照合を通す手」であって「実装」ではない。

**原則**: Figma の座標・寸法は**参照値**であり、CSS に書くのはそれをフロー配置へ変換した結果 — `display: flex | grid`・`gap`・`padding`・`margin`・`width | max-width`・`aspect-ratio`・`align-*`・`justify-*` — である。要素の位置は「親の余白と兄弟との間隔」で表現し、「親の左上からの座標」では表現しない。

**変換の手順**（セクションごと・画面種ごとに実施し、要点を対応表の実装メモへ記す）:

1. design context の layout 情報（auto layout の方向・`gap`・`padding`・`alignment`・子の `fill | hug | fixed`）を読む。auto layout が付いていればそれを flex / grid と `gap` / `padding` にそのまま対応させる
2. auto layout が無い（子が絶対座標で置かれた）フレームは、子ノードの座標差から `gap` / `margin` / `padding` を**算出**し、算出根拠（どのノード間の差か）を実装メモに書く。座標そのものは書かない
3. 幅は、デザイン幅に対する比率か `max-width` ＋ 左右 `auto` / `padding` で表現し、デザイン幅ぴったりの固定 `px` 幅を親コンテナに与えない（固定 px 幅を許すのは、アイコン・罫線・サムネイルなど内容によって伸びない要素のみ）
4. 見出し・本文・ラベル・ボタン文言など**折り返しうるテキストを含む要素は必ずフロー配置**にする。行送りは `line-height` と `margin` で作り、`top` の差で作らない
5. 変換後に数値照合（Step 3）で許容差を超える残差が出たときは、`line-height` によるハーフレディング、`letter-spacing` の末尾余白、フォントのアセント/ディセント差をまず疑い、それでも残る差は未確定要素リストへ記録して方針確認に回す。**絶対配置へ切り替えて残差を消してはならない**

**`position: absolute | fixed` の許可範囲**（限定列挙。ここに無い用途は禁止）:

- 背景装飾（背景画像・曲線・帯・楕円など、テキストを含まず親の寸法に寄与しないもの）
- 擬似要素による飾り（下線・矢印・区切り線・箇条書きマーカー）
- 画像の上に重ねる小要素（バッジ・再生アイコン・オーバーレイのフィルター層）
- `object-fit` 目的で親比率ボックスに収める `img`（親は `aspect-ratio` で高さを持つ）
- 開閉するドロワー・モーダル・固定ヘッダー・閉じるボタンなど、通常フローから外れることが仕様である UI
- `visually-hidden` ユーティリティ
- 使用ライブラリ（カルーセル等）が既定で絶対配置にする部品

いずれも次の**両方**を満たすこと: (a) 折り返しうる本文テキストを含まない（装飾に添える 1 語のラベルは除く）、(b) 親の高さが、その要素以外のフロー要素または `aspect-ratio` / `min-height` で決まる。

**禁止パターン**（発見したら Step 3 のループ内でその場でフローへ組み直す。Step 5 の統合検証でも列挙して照合する）:

- テキスト要素（見出し・本文・数値・ラベル・ボタン）を `top` / `left` で配置する
- 兄弟要素の間隔を各要素の `top` の差で表現する（`gap` / `margin` を使う）
- 親に固定高を与え、子を絶対配置で並べる（親の高さは子から決まる構造にする）
- `white-space: nowrap` で折り返しを止めて崩れを隠す（`nowrap` を使えるのは、1 語のラベル・数値・ボタン文言など折り返さないことが仕様の要素のみで、理由を実装メモに書く）
- 画面種ごとに `top` / `left` の値を書き換えて位置合わせをする（画面種で変わるのは `gap` / `padding` / `flex-direction` / `grid-template` の側）
- 「改行対応」「文言変更対応」のような後追い修正で、絶対配置を残したまま座標や `nowrap` を足す（依頼の形がこれなら、当該要素の構造をフローへ組み直す修正として扱う）

**例外の記録**: 許可範囲に該当して絶対配置を使う要素は、対応表の実装メモに「要素（セレクタ）/ 許可範囲のどれに該当するか / 親の高さが何で決まるか」を 1 行で記す。記録の無い絶対配置は Step 5 で差し戻しの対象になる。
