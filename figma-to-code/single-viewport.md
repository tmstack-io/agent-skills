# figma-to-code 片側の画面種が無い場合の導出方針（正本）

SKILL.md Step 0 手順 2 のポインタから、PC/SP の一方しか存在しない場合や 1 フレームでレスポンシブを表現しているデザインの場合にのみ読まれる。導出側の合否判定の規則もこのファイルが正本。

PC/SP の一方しか存在しない場合や 1 フレームでレスポンシブを表現しているデザインの場合は、無い側の扱い（実装対象外とするか、存在する側から導出するか。推奨: 存在する側から導出する — 実装対象外にすると実機でその画面種の表示が未定義のまま残るため）を散文提示で確認し、確定した画面種と無い側の扱いを控えて Step 1 で対応表を作成する際に先頭へ転記する — 以後の記録・キャッシュ・検証は確定した画面種のみで行う。導出を選んだ場合、導出側は確定した画面種に含めず、導出方針（元にする画面種と、幅・余白・折り返しの変換規則）と検証に用いる代表幅を、その場で Step 4 の不変条件として散文提示で承認を得て控え、Step 1 で対応表を作成する際に先頭へ転記する — 導出側の合否は数値照合の対象外とし、承認済みの不変条件への適合と目視・実効ビューポートの確認で判定し、Step 5 手順 3 の検証幅に導出側の代表幅を加える。
