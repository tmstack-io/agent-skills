# smart-commit 軽量検証 NG 時の判定と依存統合（正本）

SKILL.md [7] コミットループ手順 4 のポインタから、単位の軽量検証が NG だったとき（まだ何もコミットしていない）にのみ読まれる。対処は本ファイルの規定に限る。

- SKILL.md [7] 手順 6 の「退避の復帰」を行う
- 失敗が「他の未コミット単位への依存」由来か判定
  ├─ 依存由来 → その依存単位を index に追加ステージし（hunk はこの時点の
  │             git diff（index ↔ 作業ツリー）から生成）、統合した単位を
  │             分割プランから取り除き（後続ループで再処理しない）、
  │             メッセージを作り直して 2 から再試行
  └─ 依存でない真の失敗（型エラー・Lint 違反そのもの）→ ブロックし、
     どの単位の何が落ちたかを報告して中断。勝手に直さない

統合は「単体では型が通らないが、依存先と一緒なら通る」ケースの救済。atomic さは
下がるが自動で前進できる。
