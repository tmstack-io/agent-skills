# concertino maestro との併用（正本）

SKILL.md「maestro との併用」のポインタから、maestro（concertino と同じ収録場所の姉妹スキル）の起動中に配役した場合に、最初のブリーフを書く前に読まれる。

maestro の起動中に `--implement` を配役すると、指定した編成が実装奏者となる。切替の手順: 指揮者は実装タスクのブリーフを作る際、maestro の「奏者経路の確定」で確定した経路（サブエージェント / 同系統ペイン）へは送らず、本スキルの implement 奏者（奏者ラベル）へ「配役の規律」の手順で直接委譲する（配役中は本スキルの編成が maestro の奏者経路に優先する。配役解除後は maestro の確定済み経路に戻る）。`--review` / `--explore` の奏者がいる編成も、maestro の当該ロールのタスクについて同じ切替規則に従う。品質ゲート・委譲ブリーフの要件・検収の正本は maestro であり、本スキルが定めるのは配役（誰が弾くか）と経路（どう伝えるか）だけである。
