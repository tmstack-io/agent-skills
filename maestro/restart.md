# maestro セッション途中の変更

SKILL.md「奏者の実効モデル・エフォートの確定」の「セッション途中の変更」のポインタから、本スキルの再起動または対話での変更指示を受けたときに読まれる正本。SKILL.md の「散文提示」等の定義を引き継いだ同一コンテキストで適用する。

本スキルの引数付き再起動（Claude Code では `/maestro --implement <model>` 等）での上書きを正とし、対話での明示指示による変更も、ハーネス指定を含め再起動と同じ規則で扱う。再起動では、引数で指定したロール・軸だけを上書きし、指定の無いロールは既存の確定値を保つ（SKILL.md の「指定の無いロールは既定」の規則は初回起動にのみ適用する）。ハーネス指定の値で再起動したロールと、ハーネス指定のロールをモデルを含むモデル指定（`model` / `model@effort`）で再起動したロールは、SKILL.md「奏者経路の確定」をそのロールについてやり直し、指定の無い軸は初回起動の既定に戻す（ハーネス指定の値は値全体で置き換える。モデル・エフォートの語彙と許容値は CLI・モデルごとに異なるため持ち越さない）。`@effort` のみの再指定は経路を保ち、エフォートだけを上書きする。経路をやり直してペイン経路になったロールと、ハーネス指定のロールへの `@effort` の再指定には、`pane-route.md` の採用条件を新しい値でその時点で判定する（同系統のペイン経路の許諾を既に得ていれば再発火させない）。本スキルの再起動では、SKILL.md「引数による指定」の中止条件と `pane-route.md` の採用条件（各条件の「起動を中止」「終了」を含む）のいずれに該当した場合も、その再起動のみを中止し、既存の確定値・経路・ペインを保って理由（引数の誤りでは正しい書式）を報告する。値（経路・ハーネス・モデル・エフォート）が変わったロールの既存ペインの扱いは `pane-route.md`「運用」に従う。引数なしの再起動では、確定済みの奏者経路とロール別の値を保持し、確認ゲートとペイン経路の許諾を再発火させず、SKILL.md「起動時の宣言」のみやり直す。検収深度（`--deep` / `--fast`）は再起動で指定されたときのみ更新し、指定が無ければ確定済みの状態を保つ。
