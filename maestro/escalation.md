# maestro 失敗時のエスカレーション

SKILL.md「失敗時のエスカレーション」のポインタから、失敗を1回数えた時点で読まれる回数別手順の正本（失敗の数え方は SKILL.md 側が持つ）。SKILL.md の「散文提示」等の定義を引き継いだ同一コンテキストで適用する。

1. **1回目の失敗** → ブリーフの不足を疑い、失敗内容を踏まえて書き直して再委譲する
2. **2回目の失敗** → 深査読（SKILL.md「検収の2段階」の基準 7）で指揮者が原因を直接特定し（調査タスクでは、差分の代わりに前回ブリーフの完了条件と奏者の報告が根拠として挙げた箇所を指揮者が直接読み、完了条件・対象範囲・制約のどれが不足していたかを特定する）、ブリーフを組み直して 3 回目を委譲する
3. **3回目も失敗** → 状況・原因分析・選択肢を添えて散文提示でユーザーに相談する。**指揮者は実装を肩代わりしない**（ユーザーが明示的に「本体が直接書け」と指示した場合は、当該タスクの当該編集に限るモードの一時解除として扱い、完了後は本モードへ戻った旨を一言報告して再開する）
