# tui-harness 指揮者裁定（正本）

SKILL.md「指揮者裁定」節のポインタから読まれる規定の正本。pull 安全網が blocked で発火したときに適用する。

承認ダイアログは pull 安全網の blocked 発火で検知し、指揮者が裁定スコープとの照合で二値裁定する:

- 対象パス・コマンドが**裁定スコープ内** → 許可する。
- **範囲外** → 拒否し、呼び出し側の失敗規律へ進む。

対象パス・コマンドが表示で切れている場合は `mux.sh read --scrollback`（行数は SKILL.md「応答の受け取り」の画面読みの行数規則）で読み直して確認してから裁定する（対象不明のまま許可しない）。ダイアログの形式（文言・選択肢）と応答方法（キー送信 / テキスト送信）はハーネスごとに異なり、正本は当該 `transports/<CLI名>-tui.md` の裁定基準。

自動裁定機構を持たないハーネス（agy 等）への書き込み委譲は、承認ダイアログが頻発し指揮者裁定の回数が増える（起用の制限はしないが、コストとして受け入れる）。
