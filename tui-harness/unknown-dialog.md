# tui-harness 未知ダイアログの遭遇プロトコル（正本）

SKILL.md「未知ダイアログの遭遇プロトコル」節のポインタから読まれる規定の正本。当該 transports に明示されていない形式のダイアログに遭遇したときに適用する。

- **(a) 文言から対象が読め、裁定スコープで判定できる** → SKILL.md「指揮者裁定」の基準で裁定して続行し、文言・選択肢・応答・結果を実測ノートとして記録する。
- **(b) 判定不能** → 許可せず散文提示でユーザーに確認する。

いずれの場合も、セッション末尾に当該 transports への追記案（ダイアログ形式・応答方法・検証記録）を散文提示で示し、**承認を得てから**反映する（無承認の自己改定はしない）。
