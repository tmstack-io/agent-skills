# deep-pr-review diff サイズガード（正本）

SKILL.md フェーズ0 手順6-5 のポインタから読まれる手順の正本。差分が 3,000 行超または 40 ファイル超のときに、次の順で対処する:

(1) 生成物・lockfile・自動生成コード等の対象外候補と理由を散文提示で確認し、承認を得て
対象外に絞る。承認された除外パスを除いた差分を新しい一時ファイルへ書き出し、
**以降の `$DIFF_FILE` はこの絞り込み後のファイルを指す**（全レビュー実行者に同一の入力として
届かせる）。差し替え前の元の差分ファイルの実パスも保持し、後始末の削除対象に含める。絞った場合は対象外にしたものを最終出力の `注記:` に明記する（黙って切り捨てない）。
(2) 絞り込み後のファイルに対して再測定し、なお閾値を超える場合は、観点 #2 の差分読みのみを
変更ファイル群で複数体に分割する
（返却フォーマットは同一とし、フェーズ2 は分割前と同じ手順でマージする）。
