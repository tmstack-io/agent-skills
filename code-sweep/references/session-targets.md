# code-sweep セッション生成物の列挙（正本）

SKILL.md フェーズ1「引数なし」のポインタから読まれる列挙手順の正本。対象確認の散文提示と0件時の扱いは SKILL.md 側が持つ。

- 会話履歴中のファイル作成・編集操作（Claude Code では Write / Edit / NotebookEdit、およびシェルコマンドによるファイルの生成・書き換え）からセッション生成物を列挙する（会話に現れないファイルは加えない）。SKILL.md「対応コメント構文」が定める文書ファイルは一覧に含めず、除外した件数だけを添える（表に無い拡張子のコードファイルは含める）。
- git リポジトリ内のファイルは `git status --short` と突合して一覧の注記に使う（`git status` に現れれば「未コミット変更あり」、現れなければ「git 上は変更なし」と注記し、一覧の増減には使わない）。
- リポジトリ外（一時領域等）のファイルは「リポジトリ外」と注記して一覧に含める。
- 一覧は散文提示の一覧形式で書く。見出し行は番号と絶対パス、下位箇条書きの属性は注記（git 上の変更有無・リポジトリ外）とする。
