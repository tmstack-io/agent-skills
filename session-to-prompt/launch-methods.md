# session-to-prompt 手段別の「起動方法」セクション（正本）

SKILL.md Step 4 でテンプレートの「起動方法」セクションを書くときに読み、Step 2 で選択された手段の項だけを適用する。

- **新規セッション直実装**: 「新規セッションで `このファイルを読んで実装してください: <パス>` と指示する」旨を記載。
- **Workflow**: Claude Code のマルチエージェント実行機能。明示オプトインが必要なため、新セッションへの指示文に「ワークフローを使って」の文言を含めた起動指示を記載。加えて推奨フェーズ分割案（何を並列化し、何を検証フェーズにするか）を本文に含める。
- **Claude Code Goal**: Claude Code のバックグラウンド・非対話実行機能。途中でユーザーに質問できない前提を明記。未決事項が残っている場合はデフォルト判断の指針を必ず併記し、「起動方法」セクションの先頭に Goal への投入文（目的+完了条件の簡潔版）を置く。続けて、実行環境の Claude Code が案内する Goal の開始操作（コマンドまたは UI 手順）に投入文を渡す手順をコピペ可能な形で記載する（開始操作を実行環境で確認できない場合は、その旨と投入文だけを記載する）。
- **codex**: 単体で実装完走できる粒度まで手順を具体化し、判断保留を許さない（未決事項にはデフォルト判断の指針を必ず併記）。起動例 `codex "このファイルを読んで実装してください: <パス>"` を記載。
